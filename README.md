## Target classification

- **Target:** Books to Scrape (https://books.toscrape.com)
- **Scope:** The scraping is limited to the first 3 catalogue pages only.
- **Why this site:** It is a public practice sandbox built specifically for people to practice scraping.
- **robots.txt:** No robots file found (returned 404 Not Found).
- **Data collected:** Book titles, product URLs, prices, availability, ratings, and descriptions.
- **Why appropriate here:** Limiting the scrape to exactly 60 book records across three pages provides enough volume to test pagination and data extraction logic, while remaining small enough to prevent unnecessary load on the server.
